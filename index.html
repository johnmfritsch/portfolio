Infrastructure

Self-Hosted NAS & Home Lab

The home lab that hosts every project on this page. An ASUSTOR AS5202T runs a real production environment — multi-app reverse proxy, Docker-based services, SSL certificate management, automated backups, and external access via port forwarding — the infrastructure layer everything else here sits on top of.

Linux Nginx Apache Docker Let's Encrypt Gunicorn Plex Tautulli IDrive
Technical Details

16 GB RAM, dual 4 TB RAID storage. Three separate Nginx instances coexist on the box — a custom instance path-routes LAN traffic on 443, while ADM's own reverse proxy stays on 8443 for admin/IDrive so the two never collide. The router blocks inbound 80/443, so each externally-reachable app terminates its own SSL on a dedicated forwarded port instead of relying on the shared proxy. Boot-time persistence (service auto-start, kernel tuning) survives ADM firmware updates via a root-level init.d hook rather than config files ADM rebuilds on every boot. IDrive handles offsite backup.

Web Application Flagship

GardenBuddy

A full garden-management platform for tracking plants from seed to harvest — plantings, journal entries, yields, and seasonal history, with QR-code plant tags for at-a-glance access out in the garden, a kitchen module for tracking what happens to the harvest after it's picked, and photo backup to Google Photos. Installable as a phone app. The most complete of my self-hosted apps: multi-user with admin controls, audit logging, an in-app feedback and ticketing system, and a data model that's evolved through 45+ schema migrations as real usage uncovered new needs.

Python / Flask SQLite Gunicorn PWA Google Photos API SSL / HTTPS Nginx Self-hosted
Technical Details

Flask + SQLite behind Gunicorn (gthread workers, --preload so workers are born warm instead of taking ~6s on a cold first request). A self-healing watchdog polls a /health endpoint and automatically recycles or restarts a wedged worker — built after a real production incident where a stuck thread silently dropped roughly half of all requests for days before anyone noticed. Harvest tracking supports both single-entry and per-item measurements (weight, length, circumference) without double-counting totals, and a separate disposition model tracks what happens to the harvest after it's picked. Dev and prod run as parity-matched environments with a scripted deploy and rollback path.

Desktop Application

Plexifier

Portable Windows GUI that batch-converts video to Plex-ready MP4 so files "Direct Play" with no server-side transcoding. A four-tier decision engine (skip / copy / remux / re-encode) inspects each file with ffprobe and does the least work needed. Bundles its own PowerShell 7, HandBrakeCLI, and ffmpeg — zero install, and originals are preserved as .bak.

PowerShell WinForms GUI HandBrakeCLI ffmpeg / ffprobe H.264 / AAC / AC-3 Portable
Technical Details

The decision engine probes each file's container, video codec, and audio streams with ffprobe, then picks the cheapest tier that produces a Plex-ready result — avoiding the common mistake of blindly re-encoding an entire library when most files only need a container swap or an audio pass. Ships as a ~6,700-line PowerShell WinForms app bundling its own PowerShell 7, HandBrakeCLI, and ffmpeg — zero install footprint on the target machine — with a pre-flight-checking launcher and per-run debug logging for troubleshooting.
